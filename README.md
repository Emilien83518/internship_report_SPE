# Internship Report — SPE

## Overview

This repository contains my internship report, covering a **1-month internship (June 8 – July 8, 2026)** at **Bewizit**, a company that develops web and mobile applications for its clients.

During this internship, I worked as a **Full-Stack Developer Intern**, contributing to several ongoing products across the company's portfolio. My work focused on helping build out and structure systems so that each project would work properly, both on the frontend and backend sides.

## Projects

### [weteam](https://github.com/Bewizit/weteam)
A SaaS platform for team development, helping organizations assess and strengthen collective dynamics through surveys, diagnostics, and qualitative interviews.
- **Stack:** TypeScript, React, Next.js, Supabase, TailwindCSS, Turborepo (i18n-ready, monorepo architecture)

### [periscorp](https://github.com/Bewizit/periscorp)
The main Periscorp application: a monorepo with a PHP/GraphQL API and a Next.js web frontend.
- **Stack:** PHP (Symfony-based API with GraphQL), Next.js, pnpm workspaces, Docker, JWT (RS256) authentication

### [periscorp-deck](https://github.com/Bewizit/periscorp-deck)
A pitch deck viewer for Periscorp, used to present investor, client, and product-facing decks.
- **Stack:** Next.js, shadcn/ui, Markdown-driven slide content

## What I worked on

Across these projects, I contributed to structuring and stabilizing existing systems — helping set up and organize code so features worked reliably end to end, rather than building isolated one-off features. This involved getting familiar with each project's architecture (monorepos, GraphQL APIs, Next.js frontends) and applying consistent structure and fixes where needed.

## Purpose of this repository

This repository is used to document and organize the internship report (SPE), summarizing the context, projects, and work carried out during the internship at Bewizit.
